# ExposureIQ website

Landing page for [ExposureIQ](https://github.com/ExposureIQ-Project/ExposureIQ), the open-source attack surface management tool.

Plain HTML, CSS and JavaScript. No build step, no dependencies.

## Structure

```
.
├── index.html
├── css/
│   └── style.css
├── js/
│   └── main.js            # animated network background
├── assets/
│   └── branding/          # logo, icon, avatar, banner
└── README.md
```

## Run locally

Open `index.html` in a browser, or run a small local server:

```bash
python -m http.server 8000
# then visit http://localhost:8000
```

## Deploy

Hosted with GitHub Pages. In the repository, go to Settings, then Pages, and deploy from the `main` branch, root folder.
