Know your attack surface before someone else does

Companies forget old test sites, open a service by mistake, and rarely notice when something changes. ExposureIQ is built to catch that.

🔍

Discover

Finds subdomains, IP addresses, open ports and the software running on them, using public records and a standard port scanner.

🔄

Compare

Every scan is saved. ExposureIQ shows what is new, changed or gone since last time, because change is where risk appears.

📄

Report

Results become a professional report with severity levels, charts and recommendations, readable by engineers and managers alike.

✨

Optional AI helper. A local AI model can suggest what to fix first and draft report text. It only reads the results. It never scans, runs anything, or decides on its own, and a person always reviews its output. The tool works fully without it.

How it works

A simple pipeline, one command at a time.

  1. Scan

    Point it at a domain you own. It finds subdomains, addresses and open ports.

  2. Check

    It identifies the software in use and flags weak or risky settings, each with a severity.

  3. Compare

    It stores the scan and shows what changed since the previous one.

  4. Report

    It generates a report, with optional AI-drafted suggestions marked as drafts.

Responsible use

ExposureIQ actively probes systems. Only scan assets you own or have written permission to test. Unauthorized scanning may be illegal where you live.
